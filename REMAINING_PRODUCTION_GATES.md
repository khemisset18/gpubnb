# Portes de production non contournables

Cette release est une base renforcée, pas une certification Mainnet. Les points suivants exigent une infrastructure et/ou un audit extérieur :

- Générer et déployer le vrai Program ID Anchor.
- Ajouter une résolution de litige multisignature au contrat.
- Déployer un oracle redondant et mesurer le chemin complet vu par le client.
- Construire l'orchestrateur de workloads et sa sandbox GPU.
- Réaliser les tests d'évasion, de charge, de panne et de fraude.
- Finaliser les routes forum, chat, modération, signalements et administration.
- Effectuer revue juridique, conditions, confidentialité, fiscalité et sanctions applicables.

Mainnet doit rester désactivé jusque-là.
