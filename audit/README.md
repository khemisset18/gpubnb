# External release evidence

Do not create the approval files manually. Place signed evidence here only after completion:
- `EXTERNAL_AUDIT_APPROVED.txt`: auditor, audited commit, program ID, binary SHA-256, date and unresolved findings.
- `MULTISIG_CONFIGURED.txt`: multisig address, threshold, signers, upgrade authority and emergency process.
- `SANDBOX_PENTEST_APPROVED.txt`: tested runtime, pentest scope, report hash and accepted residual risks.
