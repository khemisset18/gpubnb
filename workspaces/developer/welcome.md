# Bienvenue dans Developer Workspace

Votre environnement temporaire contient VS Code Web, Git, Python, Node.js, Java, Go, Rust, C et C++.

- Placez les fichiers entrants dans `/workspace/imports`.
- Enregistrez les résultats à télécharger dans `/workspace/output`.
- Ne stockez jamais durablement de secret dans cet environnement éphémère.
- Exportez vos résultats avant de terminer la session.
