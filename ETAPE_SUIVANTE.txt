GPUbnb — prochaine étape unique

1. Décompresser cette archive.
2. Remplacer les fichiers du dépôt GitHub khemisset18/gpubnb par ceux de ce dossier.
3. Sur Render : New > Blueprint > sélectionner gpubnb.
4. Coller uniquement :
   - DATABASE_URL : URI Supabase Session pooler, port 5432.
   - REDIS_URL : URI Upstash TCP TLS commençant par rediss://.
5. Cliquer Apply/Deploy.
6. Ne jamais partager ces deux valeurs dans une capture ou un message.

Le site et l’API seront accessibles sur la même URL Render. Netlify n’est pas nécessaire pour cette première version.
