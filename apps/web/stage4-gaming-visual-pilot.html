Gaming : vérifier un jeu sur le bureau Windows distant

Le streaming Cloud Desktop de PC1 vers PC2 a été observé avec image, souris et clavier. Cet essai permet de mesurer manuellement l'affichage et les entrées d'un jeu déjà installé dans le compte Windows locataire. Il n'active pas le workspace Gaming officiel.

État des capacités

  • Vidéo H.264, souris et clavier : testés dans Cloud Desktop ; à revérifier avec un jeu.
  • Audio du jeu : non qualifié, aucun son distant garanti.
  • Manette : non qualifiée, aucune manette distante garantie.
  • Steam : pas de démarrage automatique ; le Helper bloque encore le workspace Gaming autonome.

Précautions obligatoires

Utiliser uniquement le bureau standard gpubnb-renter-qual de PC1. Ne jamais ouvrir la session personnelle du propriétaire, saisir ses mots de passe, partager un compte Steam personnel, ni accéder à ses fichiers. Ne pas installer de pilote, désactiver de protection Windows ni modifier le service GPUbnb.

L'essai reste dans une réservation privée sans paiement. Le navigateur PC2 utilisera le même parcours sécurisé que Cloud Desktop. L'arrêt du bureau distant ne raccourcit pas automatiquement le créneau de réservation.
