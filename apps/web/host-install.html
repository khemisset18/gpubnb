Test en cinq étapes

  1. Activez le rôle propriétaire dans votre profil.
  2. Téléchargez GPUbnb Host pour votre système.
  3. Sous Windows, extrayez entièrement le ZIP dans un dossier.
  4. Lancez GPUbnb-Host-Portable.exe puis créez un code de liaison.
  5. Saisissez ce code dans Host et attendez le premier heartbeat.
  6. Ouvrez « Mes machines », vérifiez le GPU puis publiez votre annonce.
Important

Cette version est une préversion de test non signée. Windows ou macOS peut afficher un avertissement de sécurité. Elle sert uniquement à tester GPUbnb sur Devnet, pas à héberger des charges de production.
