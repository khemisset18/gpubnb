Installer GPUbnb Host

Téléchargez l’application propriétaire officielle, puis reliez votre machine. Aucun téléchargement ne démarre automatiquement.

Recommandé pour votre appareil

Windows 64 bits

Téléchargez l’installeur EXE, vérifiez sa somme SHA-256, puis lancez gpubnb-host-windows-x64.exe. Cette préversion peut déclencher l’avertissement Windows SmartScreen car elle n’est pas encore signée.
