Parcours d’installation

  1. Activer votre espace propriétaire.
  2. Télécharger GPUbnb Host depuis cette page.
  3. Vérifier la version, le commit et le SHA-256.
  4. Installer puis lancer GPUbnb Host.
  5. Créer un code de liaison à usage unique.
  6. Saisir le code dans GPUbnb Host.
  7. Vérifier la machine avant toute publication.
Qualification actuelle
