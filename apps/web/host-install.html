Guide d’installation

  1. Activez le rôle propriétaire dans votre profil.
  2. Téléchargez GPUbnb Host avec le bouton correspondant à votre système.
  3. Installez l’application puis créez un code de liaison ci-contre.
  4. Dans Host, choisissez « Lier cette machine » et saisissez le code.
  5. Ouvrez « Mes machines » pour vérifier le heartbeat et le GPU détecté.

Les URL sont configurées dans Netlify avec GPUBNB_HOST_WINDOWS_URL, GPUBNB_HOST_LINUX_URL et GPUBNB_HOST_MACOS_URL. Une URL absente ou non HTTPS garde le bouton désactivé.
