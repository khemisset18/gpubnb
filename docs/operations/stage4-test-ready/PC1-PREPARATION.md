# PC1 GTX1650 — instructions sûres
**Aucune installation autorisée.** Vérifier sous PowerShell Windows x64: `nvidia-smi --query-gpu=name,uuid,driver_version --format=csv,noheader`; `Get-PnpDevice -PresentOnly | ? FriendlyName -Match 'GPUbnb|IddCx'`; `Get-LocalUser`; `quser`; `Get-Service *gpubnb*`. Vérifier le compte locataire distinct, les SID, le bureau console, l'Agent existant et NVENC réel au test vidéo.
Vérifier sans exporter de clé `Get-ChildItem Cert:\CurrentUser\My | ? Subject -Match 'LOCAL PHYSICAL TEST ONLY' | Select Subject,NotBefore,NotAfter,HasPrivateKey,Thumbprint`. Contrôler EKU code signing et SHA256 du certificat. Si absent/expiré, certificat de test de remplacement sous autorisation locale, jamais pin inventé ni production.
Reconstruire les 4 PE à partir du même SHA propre; établir manifeste SHA256, architecture AMD64, dépendances via dumpbin, build-info Agent, politiques worker/helper, signatures Authenticode et certificate pins. Le script `scripts/stage4-private-test-sign-copies.ps1` épingle encore les empreintes du commit 2b055992; ne pas l'exécuter avec le nouveau build avant modification vérifiée.
Après accord utilisateur uniquement: archiver installation actuelle `C:\Program Files\GPUbnb`, ACL/configuration/services/hashes et vérifier la sauvegarde; préparer staging séparé; arrêter proprement services; installer uniquement copies signées vérifiées; vérifier IddCx non modifié. Retour arrière: arrêter nouveau service, restaurer backup, vérifier hashes, ACL, service et reprise. Ne pas redémarrer automatiquement.
Le script existant `scripts/qualification-preflight-pc-a.ps1` permet ensuite une qualification plus large, à lancer volontairement après lecture.
