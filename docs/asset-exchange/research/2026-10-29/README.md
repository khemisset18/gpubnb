# Base technique Asset Exchange — livraison du 29 octobre 2026

Cette livraison est une base de recherche, de conception et de tests hors ligne.
Elle n'est pas un exchange opérationnel ou qualifié. Les capacités et règles
financières de production restent inchangées.
