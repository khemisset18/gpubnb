# Roadmap GPUbnb Workspaces

## Phase 1 — Audit

- [x] Stack, comptes, agent, réservation, paiement, tests et sécurité inspectés.
- [x] Architecture, données, risques et dépendances documentés.

## Phase 2 — Fondations

- [x] Treize manifestes versionnés et statuts honnêtes.
- [x] Compatibilité explicable et tests unitaires.
- [x] Persistance Prisma et migration.
- [x] API catalogue/analyse/activation.
- [x] Grille responsive cinq cartes et configuration propriétaire.
- [x] Commandes agent `workspaces list` et `workspaces analyze`.

## Phase 3 — Cycle de vie

- [ ] Installation consentie, test, activation et version de module.
- [ ] `WorkspaceSession`, transitions, arrêt d’urgence et nettoyage.
- [ ] Métriques, coût temps réel, audit et notifications.

## Phase 4 — Premiers espaces exécutables

1. Compute au-delà du diagnostic ;
2. Developer ;
3. AI ;
4. Cloud Desktop ;
5. API.

Les espaces de création et données viennent ensuite. Security, Gaming et audio
temps réel restent en dernier en raison de leur surface de risque.
