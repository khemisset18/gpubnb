## Historical material

Files whose names contain `RC3`, `VERIFICATION`, `STATUT_RELEASE`,
`ETAPE_1`, `FRONTEND_PREMIUM` or a dated release describe earlier preparation
passes. They are retained as project history, not as evidence that the current
commit or an external deployment passed. For setup and release decisions use
`README.md` and the current operational sources above, then verify the current
code and CI logs directly.
